Landing page moderna para una agencia de viajes y turismo, desarrollada con HTML, CSS y JavaScript. El proyecto presenta destinos destacados, paquetes turísticos, servicios de viaje y un formulario de contacto, ofreciendo una experiencia visual atractiva y responsiva para potenciales clientes.

## 🌐 Demo

👉 https://luxury-tours.vercel.app/

## 📋 Características

- Diseño responsive adaptable a dispositivos móviles, tablets y escritorio.
- Navegación de una sola página (Single Page Layout).
- Slider principal con imágenes destacadas.
- Sección de presentación de la agencia.
- Catálogo de servicios turísticos.
- Paquetes de viaje destacados.
- Preguntas frecuentes (FAQs).
- Formulario de contacto con confirmación mediante modal.
- Selección dinámica de País, Estado y Ciudad utilizando CountryStateCity API.
- Integración de Google Maps para ubicación y referencia.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Bootstrap Icons
- CountryStateCity API
- Google Maps Embed API

## 🚀 Instalación y ejecución

1. Clonar el repositorio:

```bash
git clone <url-del-repositorio>
```

2. Acceder al directorio del proyecto:

```bash
cd luxury-tours
```

3. Abrir el archivo `index.html` en el navegador o utilizar una extensión como Live Server en Visual Studio Code.
